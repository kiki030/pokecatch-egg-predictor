# PokéCatch 本地孵蛋色違預測（Chrome / Edge MV3 純文字 Popup 版）

零依賴、免編譯、純本地端運行的 Manifest V3 **純文字 Popup 彈窗** 擴充功能。平時完全不注入遊戲頁面，僅於你點擊瀏覽器工具列圖示時，單行唯讀當前遊戲分頁的 `localStorage` 存檔並呈現色違序列預測與持有蛋狀態。

## 載入與使用步驟（Chrome / Edge）

1. 開啟瀏覽器擴充功能管理頁面：
   - **Chrome**：網址列輸入 `chrome://extensions/`
   - **Edge**：網址列輸入 `edge://extensions/`
2. 開啟 **開發人員模式（Developer mode）**。
3. 點擊 **載入未封裝項目（Load unpacked）**，選擇本專案資料夾。
4. 點擊瀏覽器右上角拼圖圖示，將 **「PokéCatch 本地孵蛋色違預測」** 釘選（Pin）到工具列。
5. 切換至 PokéCatch 遊戲分頁後，點擊工具列上的擴充功能圖示即可開啟 Popup 查看（隨時可按右上角「刷新」重新讀取最新存檔）：
   - `https://pokecatch-online.app/`

## 功能摘要

- **遊戲源碼一致的雜湊號位抽籤（`egg|k|1`）**：以 `eggSlotHash(k, save)` 對應培育屋親代池（自動排除百變怪與 `NO_EGG_IDS`），精準推算每顆蛋的親代號位與繁體中文名稱。
- **固定 999 顆高效掃描**：上方四層互斥區間摘要卡（`普通親代 1/512`、`吃果普通親代 1/256`、`閃光親代 1/16`、`吃果閃光親代 1/8`）與下方「生蛋預測（999顆內）」共用同一份 999 顆掃描結果，分批每次渲染 200 筆維持流暢。
- **「隱藏第4顆以後的普通蛋」開關**：可一鍵隱藏第 5 顆以後的非色違普通蛋，保留第 1～4 顆普通蛋與全部四檔閃光蛋（保留原始序號，狀態自動記憶於 `chrome.storage.local`）。
- **內建全國圖鑑 1–1025 繁中名表（`names.js`）**：Popup 端純本地離線查表顯示寶可夢繁體中文名稱，完全不依賴遊戲畫面 DOM。
- **持有蛋清單與孵化倒計時**：列出每顆持有蛋的編號、繁體中文名稱、`k` 值、親代來源與精確到分鐘的孵化倒計時（`可孵化` / `Nmin` / `Hh` / `Hh Mmin`），閃光蛋於 Popup 面板內以金色邊框與 `✨ 閃光` 標籤高亮標示。

## 權限與安全邊界

- **最小權限宣告**：僅宣告 `"storage"`（保存頁籤、篩選與開關偏好）、`"activeTab"` 與 `"scripting"`（僅於點擊圖示且位於 `https://pokecatch-online.app/` 時，執行單行唯讀 `localStorage.getItem('gachamon-save-v1')`）。
- **完全零 DOM 查詢與零常駐注入**：不含 `content_scripts`、不查詢亦不修改遊戲原生 DOM、不掛載 `MutationObserver`、不執行背景輪詢。
- **純文字徹底 0 網路請求**：採純文字介面，不載入任何圖片資源，不發送任何外部 API 或靜態資源請求，不寫入遊戲 `localStorage`，不模擬任何自動點擊。
