# PokéCatch 本地孵蛋色違預測（Chrome / Edge MV3 純 Popup 版）

零依賴、免編譯、純本地端運行的 Manifest V3 **純 Popup 彈窗** 擴充功能。平時完全不注入遊戲頁面，僅於你點擊瀏覽器工具列圖示時，單次唯讀當前遊戲分頁的本地存檔並呈現色違序列預測與持有蛋清單。

## 載入與使用步驟（Chrome / Edge）

1. 開啟瀏覽器擴充功能管理頁面：
   - **Chrome**：網址列輸入 `chrome://extensions/`
   - **Edge**：網址列輸入 `edge://extensions/`
2. 開啟 **開發人員模式（Developer mode）**。
3. 點擊 **載入未封裝項目（Load unpacked）**，選擇本專案資料夾。
4. 點擊瀏覽器右上角拼圖圖示，將 **「PokéCatch 本地孵蛋色違預測」** 釘選（Pin）到工具列。
5. 切換至 PokéCatch 遊戲分頁後，點擊工具列上的擴充功能圖示即可開啟 Popup 查看（隨時可按右上角「刷新」重新讀取最新存檔）：
   - `https://pokecatch-online.app/`

## 功能摘要

- **四層互斥區間摘要卡**：即時顯示「普通親代 (1/512)」、「吃果普通親代 (1/256)」、「閃光親代 (1/16)」、「吃果閃光親代 (1/8)」各自距離下一次色違的顆數、`k` 值與對應親代號位。
- **1000 顆生蛋序列預測**：列出後續 1000 顆蛋的完整序列（分批每次顯示 200 筆），色違命中列以統一閃金色系標籤高亮提示。
- **持有蛋清單與閃光標記**：在 Popup 的「持有蛋」分頁列出每顆持有蛋的編號、名稱、`k` 值與親代來源，判定為閃光時僅於 Popup 面板內加上金色邊框與 `✨ 閃光` 標籤。
- **培育屋親代狀態**：讀取目前培育屋親代配置、等級與經驗條，自動偵測不可生蛋品種（`NO_EGG_IDS`）與僅放百變怪情形。

## 權限與安全邊界

- **最小權限宣告**：僅宣告 `"storage"`（保存頁籤偏好與本地寶可夢中文名快取）、`"activeTab"` 與 `"scripting"`（僅於點擊 Popup 圖示且位於支援的遊戲網域時，執行單次唯讀快照）。
- **零常駐注入**：不含 `content_scripts`、不注入懸浮面板、不掛載 `MutationObserver`、不執行背景輪詢。
- **純文字徹底 0 網路請求**：採純文字介面，不載入任何圖片資源，不發送任何外部 API 或靜態資源請求。
- **嚴格唯讀**：不修改遊戲 DOM、不寫入遊戲 `localStorage`、不模擬任何自動點擊。
